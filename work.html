Smart IoT Monitoring System

This project demonstrates a connected IoT system designed to monitor environmental conditions in real time. An ESP32 collects data from multiple sensors and sends it to a web dashboard where users can view measurements, track changes, and receive alerts.

The system can monitor values such as temperature, humidity, light intensity, and motion. The web interface presents the collected data through a clean and responsive dashboard, making it easy to understand the current state of the environment.

The project combines embedded programming, IoT communication, web development, databases, and system integration into one practical application.

Key Features

  • Real-time sensor monitoring
  • ESP32-based data collection
  • Web-based dashboard
  • Historical data visualization
  • Automatic alerts when values exceed predefined limits
  • Remote device status monitoring
  • REST API communication between the device and web application

The goal is to create a reliable bridge between physical hardware and modern web applications, demonstrating how connected devices can collect, process, and deliver useful information in real-world environments.
